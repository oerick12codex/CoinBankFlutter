Screens

  • **Login**

    • Tela login acessada com Usuarios pre-cadastrados diretamente no banco de dados

  • **Home**

    • Tela principal do aplicativo onde exibi informações do usuario como saldo e dá acesso a tela

  • **Cotação**

    • Tela que exibe as cotações de outras moedas. Possivel implementação futura de um apinel de investimentos na tabela cotações junto com as cotações das mais diversas moedas seja elas moedas digitais e moedas fiduciárias
